# A+H 协整与动态配对交易

V1.4。EF Lab 的 A+H 股协整配对交易研究看板。版本记录见 [CHANGELOG.md](CHANGELOG.md)。

A 股和 H 股不能互相兑换。这里的结果是统计套利的历史回测，不是无风险套利。p 值不是获利概率。

## 运行

```bash
cd F:\Hermes\Github\ah-pairs-dashboard
pip install -r requirements.txt
streamlit run app.py
```

命令行看一只股票。默认不允许做空 A 股；需要那一档时加上 `--allow-short-a`。

```bash
python -m ah_pairs --a 601318 --start 2018-01-01
python -m ah_pairs --a 601318 --start 2018-01-01 --allow-short-a
```

侧栏可以切换简体、繁体和英文。公司名称仍用数据里的中文。点「应用参数」后，地址栏会带上股票、语言、日期、对冲、窗口、开平仓、成交、是否做空，以及成本是法定档还是零。佣金小数、卡尔曼 δ 和再平衡带不在链接里。

行情缓存在 `data/cache`，新文件是 Parquet，旧的 CSV 仍会读取。缓存目录可以用 `AH_CACHE_DIR` 改掉；Railway 上若挂了卷，会使用 `RAILWAY_VOLUME_MOUNT_PATH`。股票池快照在 `data/ah_universe.csv`，看板侧栏可以重新从 AKShare 拉取。

全市场扫描不在页面里跑：

```bash
python -m ah_pairs.scan --start 2018-01-01
python -m ah_pairs.scan --all --start 2018-01-01
```

默认只扫流动性较好的子集。`--all` 扫描名单里的全部公司，结果写到 `data/cache/scan/`。设置 `AH_PUBLISH_SCAN=1` 时同时写到 `data/scan_snapshot/`。页面读这两处里较新的一份。流动性子集的摘要可以放进仓库的 `data/scan_snapshot/`，表上带生成日和规格；普通推送不会跑扫描。等风险组合用各对策略收益的倒数波动加权，权重滞后一天，不是无风险组合。点扫描表的一行会打开那一对。回测页的成本对照可以另加一行 H 股现金红利 20% 预扣，主回测仍用复权价；没有本地分红缓存时这一行留空。

收盘后的 z 提醒只在设置了 `ALERT_WEBHOOK_URL` 时向外发送。没有这个地址时，命令只打印报文并以 0 退出：

```bash
python -m ah_pairs.alerts --start 2018-01-01
```

默认检查 601318、601398、600036、601857。

## 方法

- 价格用复权收盘价。Yahoo 含分红再投资，东财回退是前复权，都不是港股通税后价格。H 股乘以 `HKDCNY` 后取对数。日历是 A 股和 H 股的并集。
- 协整、β 和 z 只在两边同时开市的日期上估计。单边开市日不新开仓、不调 β。已经持有的仓位计入开市一边的涨跌，停市一边的收益记 0。总收益因此和「只保留同时开市日」的旧口径不同。
- 全样本 Engle–Granger 和 Johansen 是描述统计，用了窗口内全部同时开市日的价格。残差 ADF 偏乐观，不能代替 Engle–Granger 的 p 值。
- 交易用的 β 来自滚动 OLS 或卡尔曼滤波，都只用当天以前的数据。自动选择卡尔曼 δ 时，只用评估区间之前的预热样本。z 分数的均值和标准差含当天价差。
- 默认在下一个两边都开市的交易日收盘成交。A 股因此不会在买入当日卖出。页面里可以改成信号当日收盘，那一档更乐观。
- 权重满足 `|w_A| + |w_H| = 1`。β 变动小于再平衡带时不调仓。做空 A 股默认关闭。
- 印花税默认走法定档期：A 股 2023-08-28 起卖方 0.05%，此前按 0.1%；H 股 2021-08-01 至 2023-11-16 为 0.13%，其余 0.10%。
- 样本跨过三个日历年且不少于 400 行时，walk-forward 按年扩展训练，在训练段同时选择开仓和平仓阈值，下一年只验证。更短的样本只切成前后两半。报告的是各折验证夏普的中位数、最小值和最大值。各折验证段会接成一条样本外净值。页面里这一步要点按钮。
- 年数是首尾 K 线的日历跨度除以 365.25。夏普按每年实际行数年化，不再固定乘 √252。区间用区块长度 21、400 次、种子 7 的自助法，年化因子与点估计相同。PSR 和压缩夏普概率都不是赚钱的概率。
- 稳定性地图的窗口互相重叠。Benjamini–Hochberg 比例只作参考，不是独立试验的 q 值。地图仍用固定 1 阶，摘要里的 Engle–Granger 用 AIC。
- 北向资金是两市合计净买入，不是个股持仓。2024 年 8 月 16 日后日频流向停止披露。南向资金和恒生 AH 溢价指数同样是市场层面的描述。指数高于 100 表示 A 股平均比 H 股贵。回归用 HAC 标准误，不是因果。

## 测试与部署

```bash
python -m pytest tests -q
```
